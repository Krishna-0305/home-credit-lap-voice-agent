# Home Credit LAP Voice Agent

## Overview

An AI-powered voice agent built using Retell AI to conduct preliminary qualification for Home Credit's Loan Against Property (LAP) offering.

## Features

* Customer identity verification
* Preliminary LAP eligibility screening
* Support for residential, commercial, and industrial properties
* Property ownership and original document verification
* Loan amount cap handling up to ₹75 lakh
* Occupation and bank-income verification
* Property market value and tenure collection
* Disqualification handling and loan-transfer routing
* Voice conversation handling for unclear responses and corrections

## Technology

* Retell AI
* Large Language Model (LLM)
* Prompt Engineering
* Voice Agent Simulation and Testing

## Disclaimer

The agent performs preliminary screening only. Final eligibility, interest rates, and loan approval must be confirmed by a Home Credit loan expert.
